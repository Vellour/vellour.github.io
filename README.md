# Vellour: site mirror

A static copy of the VellourVisuals site (https://vellour.wintervisuals.workers.dev) for players whose internet provider throttles Cloudflare.
The pages and pictures are served from here; accounts, the config store and prices are fetched from the real server, so a login works the same way.

Download the launcher: https://github.com/Sh1ziy/VellourVisuals/releases/latest

This repository is generated by `cloud/tools/mirror.js` in the project: do not edit it by hand.
