# Vellour

Сайт VellourVisuals: визуалы для Minecraft 1.21.4 (Fabric). https://vellour.github.io/

Скачать лаунчер: https://github.com/Sh1ziy/VellourVisuals/releases/latest

Это статичный сайт на GitHub Pages, он открывается и там, где основной адрес (Cloudflare) режется провайдером: страницы и картинки лежат здесь, а аккаунты, магазин конфигов и цены приходят с сервера (https://vellour.wintervisuals.workers.dev).

Репозиторий создаётся скриптом `cloud/tools/mirror.js` из проекта, руками его править не нужно.
